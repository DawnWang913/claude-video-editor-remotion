# 参考拆解

原片：1280×720，30 fps，容器长度 30.058 秒，H.264 + AAC。目标合成：902 帧 / 30 fps = 30.067 秒。

## 视觉系统

- 米白纸张底色 `#f5f2e8`，近黑轮廓 `#292720`，双线边缘与细颗粒纸纹。
- 界面为三栏：左侧素材 / 转场 / 文字，中央竖屏手机，右侧调整面板；底部占约 40% 的多轨时间轴。
- 重点色：芥末黄 `#f3d06c`、薄荷绿 `#86bdb0`、珊瑚红 `#c96e58`、淡紫音频波形 `#9b87c2`。
- 中文为随手书写的楷体风格；使用霞鹜文楷 TC 近似。数字和英文同样采用手写字形。
- 镜头采用缓慢推近、横向平移和回到全景；剪辑动作的瞬间切换与连续的手臂移动交错。

## 实现与差异

画面全部由 SVG / React 重建，四组插画独立可编辑。没有嵌入参考视频、截图序列或远程资源。音轨单独从用户提供的参考中提取。插画轮廓、纸张纹理、镜头位置和部分细节是人工近似；音轨与完整时长对齐，但不承诺逐帧像素相同。
